# YingoTab

极简起始页框架 —— 壁纸即主题，应用与音乐由内容仓库分发。

全屏壁纸 + 大时钟 + 搜索胶囊 + 底部 Dock。框架本体不含任何应用与数据；
应用、音乐、组件全部来自「内容仓库」（一个带 `yingotab.yml` 清单的 Git 仓库），
在设置里配置任意多个仓库 URL，按顺序合并。

## 生态

| 仓库 | 职能 |
|---|---|
| **yingo**（本仓库） | 框架：内核 / 总线 / 存储 / 内置模块（时钟·搜索·壁纸·天气·Dock·音乐·设置） |
| [yingo-template](https://github.com/yingo-server/yingo-template) | 内容仓库模板：fork 后即可构建自己的应用仓，自带 CI |
| [yingo-base](https://github.com/yingo-server/yingo-base) | 默认基础应用（翻译等 Dock 应用 + 组件示例） |
| [yingome](https://github.com/yingo-server/yingome) | 默认音乐仓库 |

## 快速开始

```bash
git clone https://github.com/yingo-server/yingo.git
cd yingo
python3 scripts/serve.py 8899        # 本地预览（支持 HTTP Range）
# 打开 http://localhost:8899
```

部署到 Netlify：仓库已含 `netlify.toml`（publish=`public`，functions=`netlify/functions`），
连接仓库即可自动部署。`functions/generate-config.mjs` 是唯一的公有函数
（生成配置文件），构建 CI 模板见内容仓库的 `.github/workflows/manifest.yml`
（`workflow_dispatch` 手动触发，不主动运行）。

## 内容仓库（yingotab.yml）

```yaml
# generated by CI, do not edit
version: 1
apps:
  - id: 'translator'
    name: '翻译'
    icon: '🌐'
    type: dock          # dock = 底部应用坞；grid = 中部组件网格
    entry: 'apps/translator/index.html'
music:
  - id: 'fontaine'
    title: '枫丹'
    artist: ''
    file: 'music/fontaine.mp3'
widgets: []             # 预留：中部组件（天气/热搜等）
```

- 每个应用一个目录：`apps/<slug>/app.json`（元数据，优先）+ `index.html`（应用本体）
- 音乐放 `music/`，元数据可选 `music/music.json`
- **CI 生成**：在仓库的 Actions 页手动触发 *manifest* workflow，自动扫描并重写 `yingotab.yml`

### 在设置中添加仓库

设置面板（右上角 ⚙）→ 内容仓库 → 添加 URL，三种模式：

| 模式 | URL 填法 | 说明 |
|---|---|---|
| `jsDeliv` | `https://github.com/<user>/<repo>` | 公开仓走 jsDeliv CDN（推荐） |
| `pages` | 任意静态站点基址 | GitHub Pages / **Netlify** / Vercel / 自建均可——把应用仓部署到 Netlify 即可吃它的全球 CDN，yml 与资源同源、MIME 正确 |
| `ghproxy` | raw 地址或 GitHub 仓库地址 | 经前缀代理加速 raw 拉取 |

多仓库按顺序拉取合并，`id` 冲突时先出现的仓库优先。

## 内置能力

- **时钟 / 搜索**：大时钟、搜索胶囊（引擎可配，`!g` 等指令直达，`/` 聚焦）
- **翻译**：Dock 内置应用，基于 Bilibili Index-Translate 模型（不可配置，需自定义请自行编写应用）
- **天气**：Open-Meteo（免费无 key）+ ip 定位；可在 VFS `/shared/weather.json` 设置 `{lat, lon, city}` 固定区域
- **壁纸**：内置 4 张渐变 + URL / 本地上传导入；动态壁纸（视频 / three.js）为预留接口（`wallpaper` 模块的 renderer 注册表）
- **音乐**：播放器壳，曲目全部来自内容仓库；设置里配置多个音乐仓库按顺序合并
- **缓存**：清单 30min / 定位 24h / 预引导 6h，全部可清

## 架构

- **9 阶段内核启动**（bootloader → userland），模块失败自动隔离
- **强类型总线**：所有模块通信经 schema 校验的命令（`bus.js`）
- **Storage Fabric**：统一 VFS（memory / localStorage / IndexedDB 三层、六区路径、权限、GC、失效广播）
- **渐进加载**：首屏三模块 < 1s，其余空闲时热注册
